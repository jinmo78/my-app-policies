# 개인 개발자 앱 홍보 커뮤니티 모음

개인 개발자 앱 홍보에 바로 활용할 수 있도록, 홍보 게시판으로 바로 연결되는 커뮤니티별 웹사이트/앱 주소를 정리합니다.

각 커뮤니티마다 규정이 다르므로, **자작 앱/프로모션 전용 게시판**을 이용하는 것을 권장합니다.

#### 글쓰기 요건 정리

1. **기본 게시판 활동**  
   가입기간 **30일** + 로그인 **14회** 이상

2. **팁과강좌 / 사용기** (2020-07-22~) — 아래 **모두** 충족  
   - 가입기간 **50일** 이상  
   - 로그인 **30회** 이상  
   - 다른 게시판 게시물 **1개** 이상  
   - 다른 게시판 댓글 **10개** 이상  

3. **직접홍보 (유료·기업회원 전용)**  
   - 기업회원만 글쓰기 가능 (일반회원 아이디가 있어도 기업회원 별도 가입 필요)
   - 절차: 신청서 작성 → 입금 → 관리자 승인
   - 요금 예: 7일 44,000원 / 15일 66,000원 / 30일 99,000원 / 60일 198,000원
   - 승인 후 홍보기간 동안 게시판 상단 노출, 하루 1회 게시물 갱신 가능
   - 기업회원은 일반 게시판 이용이 제한될 수 있음 (사용기 준비용 일반 활동과 충돌)

4. **홍보 관점 (권장 순서)**  
   - 지금: Reddit / 네이버 카페 / 에브리타임 / OKKY 등 **무료 채널 우선**
   - 클리앙 일반계정: 로그인·댓글 활동만 쌓고, 요건 충족 후 **사용기**에 개발일기 톤으로 게시
   - 직접홍보: 유료 노출이 필요할 때만 검토 (지금 일반회원으로는 불가)
