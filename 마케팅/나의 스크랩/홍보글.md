# [자작앱] 웹서핑하다 좋은 정보 놓치기 싫어서 직접 만든 링크 스크랩 앱 '나의 스크랩' 출시했습니다!

안녕하세요, 눈팅만 하다가 이번에 개인적으로 만든 앱이 있어 감히 소소하게 소개글 올립니다.

평소에 웹서핑이나 SNS를 하다가 "나중에 읽어야지", "이 정보 나중에 찾아봐야지" 하고  
카카오톡 나와의 채팅방이나 웹브라우저 북마크에 마구 쑤셔넣어 두는 습관이 있었습니다.

하지만 시간이 지나면...

1. 어디에 저장했는지 찾기가 너무 어렵고
2. 카톡 링크는 만료되거나 묻혀버리고
3. 정작 필요할 때 분류가 안 되어 있어 활용을 못 하더라고요.

기존 스크랩 앱들도 써봤지만, 기능이 너무 복잡하거나 구독료 부담이 커서  
"딱 내가 필요한 깔끔하고 가벼운 스크랩 앱을 직접 만들어보자!" 하고 주말마다 시간을 내어 개발을 시작했습니다.

이번에 iOS/Android 양대 스토어에 모두 배포를 완료하여 감회가 새롭습니다.

---

## 📌 '나의 스크랩' 핵심 기능 소개

1. **쉬운 공유 스크랩**: 웹브라우저나 타 앱에서 '공유하기' 버튼 하나로 빠르게 링크 저장
2. **깔끔한 카테고리/태그 정리**: 수집한 정보를 한눈에 알아볼 수 있는 직관적인 분류
3. **강력한 검색**: 나중에 필요한 정보를 키워드로 빠르게 탐색
4. **군더더기 없는 UI**: 광고나 불필요한 기능 없이 스크랩과 읽기에만 집중
