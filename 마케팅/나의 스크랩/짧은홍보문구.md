# 짧은 홍보 문구 (에브리타임 / 네이버 카페 / 모바일용)

에브리타임, 네이버 대표 카페(아사모, 노션 사용자 모임, 대학생 스터디 카페 등)나 모바일 환경에 맞춰 **3초 만에 쓱 읽히도록** 가볍고 직관적으로 작성한 홍보 문구 예시입니다.

게시판 분위기에 맞는 옵션을 선택해 활용해 보세요.

---

## 옵션 1. 공감 유발형 (에브리타임 / 대학생 카페 추천)

**제목:** 다들 카톡 나한테 보내기에 링크 욱여넣어 두고 안 봄...?

과제 자료나 인스타 맛집/꿀팁 링크 찾아두고 카톡 '나와의 채팅방'에 다 몰아넣었다가

막상 필요할 때 찾지도 못하고 묻힌 적 많지 않음? 😭

내가 그거 매번 못 찾아서 답답해가지고 직접 만든 스크랩 앱이야!

📌 이거 하나면 됨

아무 앱에서나 [공유하기] -> [나의 스크랩] 누르면 끝

카테고리별로 착착 정리돼서 나중에 검색으로 바로 찾음

군더더기 없이 진짜 깔끔함! (광고X)

시험기간/과제할 때 자료 모으거나 꿀팁 정리할 때 꽤 유용함!

필요한 사람은 다운받아서 써보고 피드백 주면 완전 감사... 🙏

📱 아이폰: https://apps.apple.com/kr/app/%EB%82%98%EC%9D%98-%EC%8A%A4%ED%81%AC%EB%9E%A9/id6793531420

🤖 안드로이드: https://play.google.com/store/apps/details?id=com.jinmo.myscrap&hl=ko

## 옵션 2. 핵심 요약형 (네이버 IT/생산성 카페 추천)

**제목:** [자작앱] 깔끔한 링크 정리/북마크 앱 '나의 스크랩' 만들어봤습니다.

안녕하세요! 평소에 웹서핑하다가 나중에 볼 정보나 아티클을 제대로 정리하고 싶어서 직접 만든 1인 개발 앱 **'나의 스크랩'**입니다.

복잡한 기능 없이 **'빠른 저장'**과 **'쉬운 탐색'**에만 집중했습니다.

✨ 핵심 기능

- 3초 스크랩: 사파리/크롬/SNS 등에서 공유하기 버튼으로 즉시 저장
- 직관적 분류: 태그 & 카테고리로 수집한 링크 한눈에 정리
- 스마트 검색: 제목이나 태그 검색으로 원할 때 바로 찾아보기

브라우저 기본 북마크가 어지럽거나, 가벼운 스크랩 툴 찾으셨던 분들께 추천합니다!

피드백은 언제나 환영입니다. :)

📲 다운로드 링크

- iOS App Store: https://apps.apple.com/kr/app/%EB%82%98%EC%9D%98-%EC%8A%A4%ED%81%AC%EB%9E%A9/id6793531420
- Google Play: https://play.google.com/store/apps/details?id=com.jinmo.myscrap&hl=ko
