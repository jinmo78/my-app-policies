# Privacy Policy (1941 Galaxy)

1941 Galaxy (hereinafter the "Service" or "Quartz") treats players' personal information with great care and, through this Policy, discloses the purposes of collection and use of information within the game.

## 1. Information Items Collected and Collection Methods
This game is a locally running web arcade game that does not require mandatory membership registration, thereby minimizing direct collection of users' unique personal information.
- **Voluntarily submitted information**: Player nickname entered directly by the user when registering on the global real-time leaderboard (ranking)
- **Automatically collected information**: Final score obtained, cleared stage level, game operation logs (play time, error logs), IP address
- **Collection method**: Automatically uploaded to the server through a linked API upon game clear or termination

## 2. Purpose of Collection and Use
- Building a global leaderboard and verifying fairness (legitimate score ranking placement)
- Monitoring client JavaScript tampering (blocking unauthorized score uploads)
- Obtaining statistics to correct game frame drops and browser compatibility errors

## 3. Destruction of Personal Information and Game Data
Submitted ranking nicknames and score information continue to be used for leaderboard display and are destroyed immediately upon ranking season rotation cycles (e.g., every 6 months) or when judged to be abnormal data. Users who wish to destroy their own records may request erasure by verifying their nickname via email (ilovejs97@gmail.com).

## 4. Measures to Ensure Security
- Encrypted protocol (HTTPS) applied to data upload transmission segments
- Abnormal score automatic filtering algorithm running at all times
