**1 VS 1 대결**은 같은 Wi-Fi에 연결된 두 기기끼리만 직접 통신합니다.

- 주고받는 것: 방 이름, 계단 생성용 숫자(시드), 상대가 오른 칸수
- 개발자 서버나 외부 서버를 거치지 않으며, 인터넷으로 나가지 않습니다.
- 이 기능을 쓰지 않으면 앱은 어떤 통신도 하지 않습니다.

## 4. 권한

| 권한 | 용도 |
|------|------|
| `INTERNET` | 같은 Wi-Fi 안에서 상대 기기와 직접 연결 |
| `ACCESS_NETWORK_STATE` / `ACCESS_WIFI_STATE` | Wi-Fi 연결 여부 확인 |
| `CHANGE_WIFI_MULTICAST_STATE` | 같은 Wi-Fi의 방 찾기(UDP 브로드캐스트) |

위에 적은 용도 외에는 쓰지 않습니다.
